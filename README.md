# Gramark language packs

Versioned offline dictionaries for [Gramark](https://github.com/B1Z0N/Gramark). Install a language from the app: it downloads the pinned release archive, verifies its compressed and expanded checksums, and keeps the pack available for offline study. Releases include source credits, license notices, build evidence and checksums.

Preview is a review-status badge, not a restriction: these packs download, install, analyze, support study and saved words, and reopen offline. The badge remains until the app owner personally reviews that language. English and German have no Preview badge.

Language data are source-backed, but coverage and grammar analysis vary by language. A missing or ambiguous form may remain unresolved; the release notes describe each pack’s source, selection, limitations, license and attribution. No release claims native-speaker validation or complete language coverage.
